# Universal Auto Services Ltd website

Premium static website concept for Universal Auto Services Ltd, Calgary.

## Deployment

The downloadable package puts `index.html` at the top level. Upload every extracted item to a GitHub repository, then import the repository into Vercel. Select **Other** for the framework and leave the build command and output directory blank.

For Hostinger, upload `index.html` and the `assets` folder into `public_html`.
